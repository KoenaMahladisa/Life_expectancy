# Life_expectancy
Prediction of Life expectancy
This project investigates the factors that influence life expectancy across countries using data analysis and machine learning techniques.

Life expectancy is an important indicator of population health, socioeconomic development, and the effectiveness of healthcare systems. This project examines the relationship between life expectancy and a range of health, economic, demographic, and educational factors, including immunisation coverage, disease prevalence, healthcare expenditure, GDP, population, income composition, and schooling.

The project uses a global dataset containing information on 193 countries across multiple years and aims to identify important factors associated with variations in life expectancy.
